Grateful BBQ Website
--------------------

This is the official Grateful BBQ website structure.

To view the site:
1. Open "index.html" in any web browser.
2. All styling is in /css/style.css.
3. JavaScript behavior is in /js/main.js.
4. Images should be placed in the /images/ folders with the filenames used in the HTML/CSS.

Textures:
- /images/textures/wood.jpg  (woodgrain background)
- /images/textures/parchment.png  (parchment card background)
